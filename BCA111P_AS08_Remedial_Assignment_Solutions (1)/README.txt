==================================================
- All_30_Answers.txt contains easy answers to all 30 questions in the PDF.

- Programs are written in simple beginner-friendly C++.

How to run:
1. Open a .cpp file in a C++ compiler/IDE (for example, Code::Blocks or an online C++ compiler).
2. Compile and run it.
3. Enter the values requested by the program.

Assumptions:
- Q28 factorial program accepts values from 0 to 20 to avoid overflow in its integer type.
- Q30 assumes all five subjects are out of 100.
